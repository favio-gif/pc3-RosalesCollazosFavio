## Descripción

Portafolio web personal desarrollado para presentar proyectos de diseño y tecnología. Cuenta con una interfaz adaptable a diferentes dispositivos y efectos interactivos realizados con CSS.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Efectos y animaciones

Se aplicaron tres transformaciones CSS en las tarjetas de proyectos:

- Rotate: rotación al pasar el cursor.
- Scale: aumento de tamaño de la tarjeta.
- Translate: desplazamiento del elemento.

También se utilizó perspective y preserve-3d para crear un efecto de profundidad y rotación 3D.

Las animaciones se desarrollaron con @keyframes para el movimiento de elementos, la aparición del contenido y el indicador de carga.
